# awg3tg — Telegram-бот VPN-сервиса на AmneziaVPN (AmneziaWG 3.x + VLESS)

Бот для продажи VPN по подписке на собственных серверах с протоколами **AmneziaWG 3.0 / 3.1**
(совместим и с AWG 2.0 / legacy 1.x) и **VLESS (XRay)**, установленными через приложение
AmneziaVPN, в духе популярных VPN-ботов: аккаунт в Telegram,
к нему привязаны устройства (ключи), **несколько серверов в разных странах**, подписка со сроком
и лимитом устройств, оплата, скидка новичкам, рефералы, статистика трафика и полноценная админка.

## Возможности

### Для клиента
* **Аккаунт** создаётся автоматически при первом сообщении боту.
* **💳 Покупка**: тариф → оплата. Подписка одна на все серверы — страна выбирается при создании
  каждого устройства.
* **🔑 Мои устройства** — к аккаунту привязываются отдельные ключи. При добавлении клиент
  выбирает **сервер (страну)** — если их несколько, — затем **протокол** (🛡 AmneziaWG или ⚡ VLESS — только те, что есть на сервере) и вводит
  название устройства («Мой айфон»). Для каждого: получить ключ повторно, **сменить локацию**,
  переименовать, удалить, статистика трафика, статус 🟢 онлайн.
  * AmneziaWG — ключ `vpn://`, файл `.conf` и QR-код для AmneziaVPN;
  * VLESS — ссылка `vless://` и QR-код для AmneziaVPN, v2rayNG, Hiddify, Streisand, FoXray.
* **Подписка одна на все страны**, лимит устройств общий (например, телефон в Германии и ноутбук
  в Нидерландах).
* **➕ Ещё устройство** — если все слоты тарифа заняты, в «Мои устройства» появляется кнопка
  докупить слот (по умолчанию 100 ₽ за 30 дней, `SLOT_PRICE` / `SLOT_DAYS`). Оплата так же, как тарифа.
  За 3 дня до конца слота приходит напоминание с кнопкой «🔁 Продлить слот». Если слот закончился,
  самое новое устройство отключается (не удаляется) и снова заработает после покупки слота.
* **👤 Профиль** — срок подписки, сколько устройств занято, трафик за сегодня / месяц / всё время.
* **💳 Тарифы** — тарифы «срок + число устройств», продление добавляется к оставшемуся сроку.
  По умолчанию: 1 месяц — 100 ₽, 3 месяца — 300 ₽, 6 месяцев — 600 ₽, 12 месяцев — 1200 ₽, всё на 2 устройства.
* **🔥 Скидка новичкам** — кто ещё ни разу не оплачивал, получает первый месяц за полцены (50 ₽);
  предложение показывается сразу при входе в бота. Цена считается на сервере, подделать её нельзя.
* **👥 Пригласить друга** — реферальная ссылка, +7 дней за каждого друга, оплатившего подписку.
* **Напоминания** за 3 дня и за 1 день до конца подписки и уведомление об окончании.
* Когда подписка заканчивается, ключи **отключаются на сервере, но не удаляются**: после
  продления те же ключи снова работают, перенастраивать приложение не нужно.

### Автооплата картой (ЮMoney, для физлица)
Работает на обычном кошельке ЮMoney — ИП, самозанятость, домен и сайт не нужны.
1. Клиент выбирает тариф (или доп. слот) и нажимает «💳 Оплатить картой» — открывается страница
   ЮMoney, где можно заплатить любой банковской картой.
2. Бот раз в 30 секунд смотрит историю входящих переводов кошелька и находит платёж по уникальной
   метке счёта. Подписка/слот активируются сами, клиенту приходит «✅ Оплата получена!»,
   админам — короткое уведомление «💰 Автооплата». Кнопка «🔄 Я оплатил — проверить» проверяет сразу.
3. Сумма сверяется с ценой: комиссия ЮMoney (~3 %) списывается с получателя, поэтому платёж
   засчитывается, если зачислено не меньше 95 % цены (`YOOMONEY_FEE_PERCENT`). Если клиент
   заплатил меньше (например, исправил сумму в ссылке), платёж уходит админу на ручную проверку.
4. Одна операция не может оплатить два счёта; оплата по старой ссылке тоже засчитывается.

**Подключение (один раз):**
1. Кошелёк ЮMoney со статусом «Именной» или «Идентифицированный» (у анонимного маленькие лимиты).
2. Получите токен: на сервере `docker exec -it awg-bot python -m bot.yoomoney_auth` (или локально
   `python -m bot.yoomoney_auth`) и следуйте подсказкам — регистрация приложения на
   yoomoney.ru/myservices/new, разрешение доступа, копирование адреса из браузера.
   Токен даёт доступ **только на просмотр** баланса и истории — перевести деньги с ним нельзя.
3. Впишите `YOOMONEY_TOKEN=…` в `.env` и перезапустите бота (`docker compose up -d`).
4. Проверьте покупкой за небольшую сумму (например, временно поставьте тариф за 2 ₽ в админке).

Если `PAYMENT_DETAILS` задан, у клиента остаётся и кнопка «🧾 Перевод по реквизитам» (ручная оплата
ниже). Чтобы принимать только картой — уберите `PAYMENT_DETAILS` из `.env`.

### Оплата по реквизитам (вручную)
1. Клиент выбирает тариф и видит ваши реквизиты (`PAYMENT_DETAILS`).
2. Нажимает «✅ Я оплатил» и отправляет скриншот/чек (фото, файл или текст).
3. Админам приходит заявка с чеком и кнопками **✅ Подтвердить / ❌ Отклонить**.
4. После подтверждения подписка продлевается, лимит устройств ставится по тарифу,
   клиенту и пригласившему его (бонус) приходят уведомления. Повторное нажатие не продлит дважды.

### Админка (`/admin` или кнопка «🛠 Админка»)
* **👥 Пользователи** — список с фильтрами (все / с подпиской / без подписки / бан), страницы, поиск
  по ID, @username или имени.
* **Карточка пользователя**: подписка, устройства, трафик, оплаты, рефералы, кто пригласил. Действия:
  продлить на +7 / +30 / +90 / ±N дней, обнулить подписку, лимит устройств ±1,
  **🧩 доп. слоты устройств** (добавить, продлить ±30 дней, удалить), список устройств
  (получить ключ, удалить, перенести на другой сервер, создать новое), история платежей,
  написать сообщение, бан / разбан, удалить аккаунт.
* **🖥 Серверы** — добавить / изменить / удалить сервер, статус 🟢/🔴, какие протоколы на нём
  есть (AWG / VLESS), устройства и онлайн, трафик; скрыть сервер для новых клиентов;
  **перенести всех клиентов** с сервера на другой (например, если сервер заблокировали).
* **📢 Оповещение всем** — выбираете аудиторию (все / с подпиской / без подписки / **клиенты
  конкретного сервера**), и дальше каждое ваше сообщение (текст, фото, видео, файл) бот сразу
  пересылает им — пока не нажмёте «⏹ Выйти». Удобно, когда сервер заблокировали и нужно быстро
  объяснить людям, что происходит.
* **💳 Платежи** — заявки, ожидающие проверки.
* **📊 Статистика** — пользователи (новые за день / месяц), активные и платные подписки, устройства
  и онлайн, выручка за месяц и всего, трафик, разбивка по серверам, топ-10 по трафику за месяц.
* **📦 Тарифы** — добавить, изменить, скрыть, удалить.
* **🧹 Неактивные** — аккаунты без подписки, которые давно не заходили в бота и не подключались
  (14 / 30 / 60 / 90 дней), удаление пачкой.
* Команды: `/user ID|@ник`, `/extend ID дни`, `/ban ID`, `/unban ID`, `/msg ID текст`,
  `/inactive дни`, `/keys`, `/backup`.
* Администраторам подписка не нужна, лимит устройств не действует.

### Надёжность
* Бот каждые 2 минуты проверяет серверы. Если сервер не отвечает — админам приходит
  уведомление, а клиентам эта страна не предлагается, пока сервер не поднимется. Когда сервер
  вернётся, бот сам доделает то, что не смог (например, снимет ключи с истёкшей подпиской).
* Падение одного сервера не мешает работе остальных.
* **Резервная копия** базы и SSH-ключа бота раз в сутки приходит админам в Telegram
  (и по команде `/backup`). Если сервер с ботом умрёт — распакуйте архив в папку бота на
  новом сервере, и все клиенты, подписки и ключи на месте.

### База данных
SQLite (`data/bot.db`, режим WAL) — для VPN-сервиса этого достаточно с большим запасом,
отдельный сервер БД поднимать не нужно. Таблицы: пользователи, серверы, устройства, тарифы,
платежи, суточная статистика трафика.

Статистика трафика собирается каждые 5 минут из `awg show dump` со всех серверов и копится
по дням; сброс счётчиков при перезапуске контейнера учитывается.

## Почему старые боты не работают

В AmneziaWG 3.x (AmneziaVPN 5.0.x, июнь–август 2026) у протокола появились новые параметры,
которые **обязаны совпадать у клиента и сервера**:

| Параметр | Что это |
|---|---|
| `HeaderProtectionKey` | шифрование заголовков пакетов |
| `ContentPaddingAddition` | случайное дополнение пакетов |
| `RekeyAfterTime`, `RekeyTimeout`, `RejectAfterTime`, `KeepaliveTimeout`, `MaxHandshakeAttempts` | рандомизированные тайминги |
| `RandomTrailers`, `DisableCookies` | переключатели |
| `PersistentKeepalive = 25-35` | теперь задаётся диапазоном |

Кроме того, начиная с AWG 2.0 сервер живёт в контейнере `amnezia-awg2` с конфигом `awg0.conf`
(раньше — `amnezia-awg` / `wg0.conf`), `H1–H4` стали диапазонами, появились `S3`, `S4`, `I1–I5`,
а в ключе `vpn://` — поле `format_version`. Старые боты не знают этих полей, поэтому выдают
конфиг, который не проходит рукопожатие.

Этот бот **не хардкодит параметры**: при каждой выдаче он читает `[Interface]` из
серверного `awg0.conf` и переносит в ключ все параметры обфускации (включая `I1–I5`, которые
приложение Amnezia хранит в серверном конфиге закомментированными строками `# I1 = …`).
Формат `vpn://` повторяет `ExportController` из исходников amnezia-client.

## VLESS (XRay)

Бот работает с контейнером `amnezia-xray`, который создаёт приложение AmneziaVPN
(«Протоколы» → «XRay»), точно так же, как это делает само приложение:

* клиент добавляется в `inbounds[0].settings.clients` файла `/opt/amnezia/xray/server.json`,
  после чего контейнер перезапускается (Xray не умеет перечитывать конфиг на лету) — VLESS-клиенты
  этого сервера переподключаются за пару секунд, AmneziaWG это не затрагивает;
* перед перезапуском бот проверяет новый конфиг командой `xray run -test` — сломанный конфиг
  не будет применён;
* ссылка `vless://` собирается из настроек сервера (Reality/TLS, SNI, ключ, shortId, транспорт
  raw/xhttp/mKCP), поэтому если вы поменяете настройки XRay в приложении, ключи из бота
  подхватят их;
* для статистики трафика бот включает в `server.json` встроенный Stats API Xray. Если приложение
  Amnezia перезапишет конфиг при смене настроек XRay, бот вернёт статистику при следующем
  изменении клиентов. У VLESS нет «рукопожатий», поэтому «последняя активность» — это время,
  когда по ключу шёл трафик.

## Как это работает

```
                       ┌─ local ─► amnezia-awg2 + amnezia-xray   (сервер, где запущен бот)
Telegram ──► бот + БД ─┼─ SSH ───► amnezia-awg2 + amnezia-xray   🇳🇱
                       └─ SSH ───► amnezia-awg2 + amnezia-xray   🇫🇮
   AWG:   awg0.conf → awg syncconf (без разрыва соединений) → clientsTable
   VLESS: server.json → xray run -test → docker restart amnezia-xray → clientsTable
```

* **Бот ставится один** — на любой из ваших серверов (или на отдельный VPS). На остальных
  серверах нужны только AmneziaWG и/или XRay, установленные приложением AmneziaVPN, и SSH-ключ бота.
  Какие протоколы есть на сервере, бот определяет сам и показывает клиентам только их.
* Ключи X25519 генерируются в боте, IP выбирается первый свободный в подсети сервера.
* Новый пир сразу применяется через `awg syncconf` — перезапуск не нужен.
* Клиент добавляется в `clientsTable`, поэтому он **виден в приложении AmneziaVPN**
  (Сервер → Протоколы → AmneziaWG → Пользователи) с именем вида `Мой айфон | @username`.
  Удалять ключи лучше через бота, чтобы база и сервер не расходились.
* Если вы поменяете параметры протокола в приложении, кнопка «📤 Получить ключ» выдаст ключ
  уже с новыми параметрами.
* В приложении AmneziaVPN сервер будет подписан как `MyVPN 🇩🇪 Германия`.

## Установка

### Попробовать на своём компьютере (демо-режим, без VPN-серверов)

В демо-режиме бот сам создаёт три эмулированных сервера (🇩🇪 Германия, 🇳🇱 Нидерланды,
🇫🇮 Финляндия) с AmneziaWG и VLESS в папке `data/mock-servers`: работают меню, выбор страны и протокола, перенос, подписки,
оплаты, админка, статистика (трафик имитируется случайными числами). Выданные ключи
настоящие по формату, но никуда не подключаются.

1. Установите Python 3.11+ (на Windows при установке отметьте «Add python.exe to PATH»).
2. Создайте тестового бота у [@BotFather](https://t.me/BotFather) и узнайте свой ID у
   [@userinfobot](https://t.me/userinfobot).
3. В папке проекта:

   ```bash
   python -m venv .venv
   # Windows:      .venv\Scripts\activate
   # macOS/Linux:  source .venv/bin/activate
   pip install -r requirements.txt
   ```

4. Создайте в корне проекта файл `.env`:

   ```ini
   BOT_TOKEN=токен_тестового_бота
   ADMIN_IDS=ваш_id
   AWG_MOCK=1
   STATS_INTERVAL=60
   ```

5. Запустите `python -m bot` и напишите боту `/start`.

Админу подписка не нужна, поэтому путь клиента (скидка новичка, оплата, лимиты, окончание
подписки) удобнее смотреть со второго аккаунта Telegram — или временно уберите свой ID из
`ADMIN_IDS`. Чтобы проверить окончание подписки, нажмите в карточке пользователя
«⏹ Обнулить подписку». Чтобы «уронить» демо-сервер, создайте пустой файл `DOWN` в его папке
`data/mock-servers/<номер>/` — через пару минут придёт уведомление.

Демо-данные лежат в `data/` — удалите папку, чтобы начать с чистого листа.

### Боевая установка (например, 3 сервера: 🇩🇪, 🇳🇱, 🇫🇮)

**1. На каждом сервере установите AmneziaWG и XRay** через приложение AmneziaVPN
(«Добавить сервер» → «Свой сервер», IP + логин + пароль SSH, затем в «Протоколы» добавьте XRay).
Приложение создаст контейнеры `amnezia-awg2` и `amnezia-xray`.

**2. Создайте бота** у [@BotFather](https://t.me/BotFather) и узнайте свой Telegram ID
(например, у [@userinfobot](https://t.me/userinfobot)).

**3. Запустите бота на одном из серверов** (например, в Германии):

```bash
git clone https://github.com/che2281337/awg3tg.git
cd awg3tg
cp .env.example .env
nano .env            # BOT_TOKEN, ADMIN_IDS, PAYMENT_DETAILS, SUPPORT, SERVER_LOCATION, SERVER_FLAG
docker compose up -d --build
docker compose logs -f
```

При первом запуске бот сам найдёт AmneziaWG на этом сервере и добавит его как
`SERVER_FLAG SERVER_LOCATION` (например, `🇩🇪 Германия`).

**4. Подключите остальные серверы** в боте: «🛠 Админка → 🖥 Серверы → ➕ Добавить сервер».
Бот покажет команду с его SSH-ключом — выполните её на сервере в Нидерландах:

```bash
mkdir -p ~/.ssh && echo 'ssh-ed25519 AAAA… awg3tg-bot' >> ~/.ssh/authorized_keys
```

и отправьте боту строку `Нидерланды | 🇳🇱 | 5.6.7.8`. Бот подключится, проверит AmneziaWG и
добавит сервер. То же самое для Финляндии.

Нестандартный SSH-порт или пользователь не root (с `sudo` без пароля):
`Нидерланды | 🇳🇱 | 5.6.7.8 | admin@5.6.7.8:2222`.

> Бот запоминает ключ SSH-сервера при первом подключении и откажется подключаться, если ключ
> изменится (защита от подмены сервера). Если вы переустановили сервер — нажмите
> «🔑 Сбросить SSH-ключ сервера» в его карточке.

Бота можно держать и на отдельном VPS без VPN — тогда добавьте все три сервера через админку.
Переехать потом просто: восстановите резервную копию на новом сервере.

### Вариант без Docker

```bash
apt install -y python3-venv
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env && nano .env
python -m bot
```

Пример юнита systemd (`/etc/systemd/system/awg-bot.service`):

```ini
[Unit]
Description=AmneziaWG Telegram bot
After=docker.service

[Service]
WorkingDirectory=/opt/awg3tg
ExecStart=/opt/awg3tg/.venv/bin/python -m bot
Restart=always

[Install]
WantedBy=multi-user.target
```

### Восстановление из резервной копии

Распакуйте архив `backup_….zip` в папку бота (появятся `data/bot.db` и `data/ssh/`) и
запустите бота. Клиенты, подписки, ключи и подключения к серверам восстановятся.

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | токен бота |
| `ADMIN_IDS` | — | ID админов через запятую |
| `SERVER_NAME` | `AmneziaWG` | название сервиса |
| `SERVER_LOCATION`, `SERVER_FLAG` | `Основной`, `🌐` | как назвать сервер, на котором запущен бот |
| `SERVER_HOST` | авто | публичный IP/домен этого сервера для `Endpoint` |
| `TZ_NAME` | `Europe/Moscow` | часовой пояс |
| `PAYMENT_DETAILS` | — | реквизиты для оплаты (HTML, `\n` — перенос) |

Тарифы по умолчанию (1 / 3 / 6 / 12 мес.) создаются при первом запуске — поменяйте их в
«🛠 Админка → 📦 Тарифы».

## Клиенты

* **AmneziaVPN 5.0.1.5+** — нужен для AWG 3.1 (self-hosted). Для серверов AWG 2.0 подойдут и
  более старые версии 4.8.x.
* Файл `.conf` можно импортировать и в **AmneziaWG**, если его версия поддерживает параметры AWG 3.x.

## Безопасность

* Доступ к `/var/run/docker.sock` и SSH-ключ бота (`data/ssh/`) фактически дают root на ваших
  серверах — не давайте посторонним доступ к серверу с ботом и к резервным копиям.
* Приватные ключи клиентов хранятся в `data/bot.db` (нужны для повторной отправки и
  восстановления ключа после продления) — так же, как их хранит само приложение Amnezia.
* Состояния диалогов (ввод названия, чека и т.п.) хранятся в памяти и сбрасываются при перезапуске
  бота — данные в базе при этом не теряются.
